## Quick Use

**Confused about current state?** → Run REFLECT<br>
**Need direction and movement?** → Run PROJECT<br>
**Ready to ship?** → Run READINESS

Copy-paste prompts included in each file.


## Claude Code Skills

Install for use with `/readiness` command:

```bash
mkdir -p ~/.claude/skills/readiness
cp skills/readiness.md ~/.claude/skills/readiness/SKILL.md
```
